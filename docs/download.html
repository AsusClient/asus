Install Fabric for 1.21.11

Run the official Fabric installer and create a 1.21.11 profile. Java 21 or newer is required.

2

Add Fabric API

Place Fabric API in %appdata%/.minecraft/mods. The client will not start without it.

3

Drop in asus.wtf

Put the downloaded jar in the same mods folder. Do not rename it or unpack it.

4

Launch and sign in

Start the Fabric profile. Open the menu with Right Shift and sign in from the account card.

Verify before you run it

Compare the SHA-256 above with the file on your disk. If it differs, delete the file and download it again. Never run a build from a mirror that is not listed here.

Server rules still apply

Use the client on private worlds and servers that permit client mods. Some modules change movement or combat and can be detected by a server.
