Systems

What the build includes

Each card describes behaviour that exists in the client, not a concept render.

P

Prism 2.0

Rounded panels, inline module settings, a live search field, keyboard navigation and a compact layout that stays readable at GUI scale 1 and 4.

16

Sixteen themes

The original six plus Midnight, Inferno, Cyberpunk, Emerald, Bloodmoon, Lavender, Arctic, Sunset, Obsidian and Amethyst Night. Each has a palette, border treatment and animated backdrop.

3D

Cape maker

Live 3D preview, pixel painting, palette, transparency, undo and redo, PNG import and export, saved cape library and vanilla mapping guides.

AI

Dia SMP automation

Collision-aware 3D pathfinding, stuck detection, hole and web escape, water decisions, Auto Bubble Web, rotation control and a readable debug panel.

R

Render-aware cosmetics

Vanilla armour trims, banner-pattern shields and capes drawn on local render-state copies. Transparent pixels stay transparent and shaders cannot make opaque pieces see-through.

↻

Secure updates

HTTPS-only manifests, version checks and a published SHA-256 for every release. The update card reports the hash it was offered before you run anything.

Boundaries

What it will not do

Being clear about the edges is part of the product.

No anti-cheat promises

The client uses normal player input. It does not bypass screens, spoof packets or claim to be undetectable. Servers can inspect movement and combat.

No dragon assets

Dragon models, animations and menu entries are paused in this build. Their code is kept for a future restoration, but nothing dragon-related renders or appears in active cosmetics.

No fake buttons

Download links point at published files, account forms call the real authentication service, and admin actions are authorised by the server, not by hiding a button.
