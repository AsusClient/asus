01 — What is in the box

Built like a tool,
not a paywall.

Everything runs client-side on Fabric. Every screen is drawn on the GPU, every panel is laid out from scratch, and every feature ships enabled from the first launch.

Layout 01

Prism

One pane. A category column down the left, an accordion list on the right. Click a row to toggle it, click the plus to unfold that module's settings right underneath it — no side panels, no overlapping windows, nothing covering the list.

  • Inline settings with sliders, modes, colours and keybinds
  • Fuzzy search across every category with /
  • Scroll wheel on the category column flips categories
Layout 02

Classic Deck

The three-pane window: page tabs across the top, category chips under them, and a card catalog that docks its inspector and drawer beside the window instead of on top of it.

  • Auto-scales to your monitor and remembers its size
  • Configs, friends, macros, scripts and HUD pages
  • Docked panels — the catalog never gets covered

Stream-proof by default

The SS-Proof overlay draws the menu and HUD on a capture-excluded layer, with its own pointer sized to your display so it never balloons or shrinks. What your viewers see is the game, nothing else.

Fifteen themes

Amethyst, Ruby, Emerald, Ocean, Sunset, Rose, Midnight, Gold, Slate, Teal, Catppuccin, Granite, Nero Portoro, Liquid Glass and asus.wtf. Or take the highlight colour and set your own.

HUD editor

Drag every element where you actually want it — arraylist, target HUD, armour, potions, keystrokes, watermarks. Per-element fonts, colours and scale, saved per config.

Studio scripting

Write routines in the built-in editor and run them from a macro or a keybind. Loops, conditions, timers, movement primitives and a live log — no rebuild between runs.

Configs that behave

Named configs, drag-to-load, per-server auto-load and a shareable file format. Switch between a bedwars set and a lifesteal set without touching a single setting.

One key, one machine

Paste the key once and it binds to that install. The answer is cached, so the client keeps working for 72 hours without reaching the key server — and a revoked key stops working on the next check. Lost a machine? Ask for a reset in the Discord.

05 — Questions

The short answers.

Where do I get a key?

In the Discord — the key channel. One key unlocks one machine. Resets for a new PC are handled there too.

Does it need an account or Discord login in-game?

No. The client only talks to the key server, and only with the key plus a hashed install id. No username, no email, no Discord token ever reaches the client.

What is the site account for?

The account opens the dashboard, which keeps the builds and install steps together. The free build downloads without one; the full build unlocks on your account with a working key. The client still asks for that key in game.

What happens if the key server is down?

The last successful check is cached for 72 hours, so a temporary outage does not lock you out. Past that, the menu stays closed until a check succeeds.

Which versions and loaders?

Minecraft 1.21.11 on Fabric loader 0.20.1, built against Fabric API 0.141.6. It needs Java 21 or newer; Java 25 is what it ships built on.

Will it run with Sodium and Iris?

Yes. The renderer is separate from Sodium's chunk pipeline, and shaders work with the menu. Mod Menu and Cloth Config are optional — the settings also live inside the menu itself.

Can servers detect it?

Any client-side movement or combat module changes packets, and any anticheat that watches those packets can flag them. Keep blatant modules off on servers you care about; ghost settings exist for exactly that reason.

What does SS-Proof actually do?

It draws the menu and HUD onto an overlay layer that capture APIs skip, then draws its own pointer at the display's real pixel density. Streams and recordings see the game only.

Where do configs live?

In .minecraft/config/asus_wtf/ as readable files. Copy them between machines, share them, or keep a separate set per server.
