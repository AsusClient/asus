08 — Questions

The short answers.

Where do I get a key?

From the key channel in the Discord. One key unlocks one machine; resets for a new PC are handled there too.

Does the client need my Minecraft account?

No. The client only sends the key plus a hashed install id to the licence server. No Microsoft password, email or Discord token is ever read.

What happens when the backend is down?

A valid key stays valid. The last successful check is cached for 72 hours, and a network error is reported as a network error — never as an expired or revoked key.

Will it run with Sodium and Iris?

Yes. The client renders separately from Sodium's chunk pipeline, and companions and capes use an opaque layer so shaders cannot make them see-through.

Are updates automatic?

No. The client checks the published manifest, shows an in-game notice when a newer build exists and only displays HTTPS links. It never auto-installs or executes anything from a response.

Can I manage testers without giving them a paid key?

Administrators can create expiring, audited IP and HWID exemptions; usernames and account IDs annotate a normal key instead of replacing one. Every exemption is checked on the server, never by the client.

Does it work on private servers?

It is built for private worlds, testing and servers that allow client mods. Any module that changes movement or combat can be detected by a server; use it only where the server permits it.
