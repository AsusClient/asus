Install

Three steps

Full guide
01 Install Fabric

Run the Fabric installer for 1.21.11 with loader 0.20.1, then launch once so the mods folder exists.

02 Drop the jar

Put the jar above into .minecraft/mods next to Fabric API, then start the game.

03 Paste your key

Press Right Shift, paste the key and hit Unlock. After that the menu opens normally.
